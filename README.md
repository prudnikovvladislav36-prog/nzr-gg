# NZR.GG v1.6

Текущая production-сборка статического сайта NZR.GG для GitHub Pages. Включает 14 реальных публикаций, чистые 16:9 обложки, тёмную/светлую тему и браузерную CMS в /admin/.

# NZR.GG — v0.8 Admin Publisher

## Исправлено
- на странице статьи восстановлена общая шапка NZR.GG;
- активная рубрика статьи определяется до отрисовки общей навигации.

## Добавлено
- `/admin/` — форма публикации материалов непосредственно через сайт;
- загрузка обложки;
- NEWS / ESPORTS / UPDATES / INDUSTRY;
- теги, дата, slug, описание и полный текст;
- preview;
- черновик / публикация;
- публикация через GitHub API;
- автоматический commit и последующий GitHub Pages deploy.

## Безопасность
Токен не хранится в исходниках и не встроен в сайт.
Используйте fine-grained GitHub token только для репозитория `nzr-gg` с Contents: Read and write.
