# NZR.GG — v0.7.1 Layout Hotfix

Исправлена ошибка разметки главной страницы в v0.6/v0.7:
- HERO был открыт как `<article>`, но ошибочно закрывался `</a>`;
- первая карточка ESPORTS была открыта как `<a>`, но ошибочно закрывалась `</article>`.

Из-за этого браузер перестраивал DOM и ломал CSS Grid: правая часть Hero уезжала и появлялись большие пустые области.

Контентная система v0.7 сохранена без изменений.
