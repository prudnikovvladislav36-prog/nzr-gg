# NZR.GG — v0.7 Content System

Рабочая медиа-структура NZR.GG с упрощённой системой публикаций.

## Главное изменение
Для новой статьи больше не требуется создавать отдельный HTML-файл.
Публикации хранятся в `content.js`, а рубрики, поиск и страница материала собираются автоматически в браузере.

## Возможности
- NEWS / ESPORTS / UPDATES / INDUSTRY
- единый шаблон статьи
- опубликованные материалы и черновики
- дата и автор
- теги
- поиск
- похожие материалы
- состояние 404 для неверного slug
- копирование ссылки на материал
- GitHub Pages без backend

Подробная инструкция: `PUBLISHING.md`
