# NZR.GG — прототип сайта v0.1

Это первая рабочая фронтенд-версия сайта NZR.GG.

## Что уже есть
- адаптивная главная страница;
- фирменный black/gold стиль;
- NEWS / ESPORTS / UPDATES / INDUSTRY / LIVE;
- блок ближайших стримов;
- блок матчей;
- фильтрация последних публикаций;
- мобильное меню;
- модальное окно поиска;
- roadmap будущей платформы.

## Как открыть
Просто откройте `index.html` в браузере.

## Как бесплатно опубликовать
Самый простой путь:
1. создать репозиторий на GitHub;
2. загрузить файлы из этой папки;
3. подключить репозиторий к Cloudflare Pages;
4. Build command оставить пустым;
5. Output directory — `/`;
6. после публикации подключить `nzr.gg` в Cloudflare.
