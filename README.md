# NZR.GG — сайт v0.2 Visual Upgrade

Вторая версия прототипа NZR.GG.

## Изменения
- усилена фирменная black/gold айдентика;
- добавлена локальная cinematic-графика;
- новый hero-блок;
- tactical/angular рамки;
- улучшены карточки и интерактивные состояния;
- добавлены микроанимации;
- улучшены LIVE и ESPORTS блоки;
- сохранена адаптивность;
- сайт по-прежнему работает как статический HTML/CSS/JS и подходит для GitHub Pages.

## Обновление на GitHub Pages
Замените в корне репозитория:
- `index.html`
- `styles.css`
- `app.js`

И добавьте папку:
- `assets/nzr-concept.png`

После commit GitHub Pages автоматически обновит сайт.
