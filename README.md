# NZR.GG — v0.6 Media Structure

Первая версия, где NZR.GG уже работает как настоящий многостраничный медиа-сайт.

## Добавлено
- `/news/`
- `/esports/`
- `/updates/`
- `/industry/`
- `/article/?slug=...`
- общая база материалов `content.js`
- общий header/footer/search для внутренних страниц `site.js`
- шаблон рубрики `category.js`
- шаблон статьи `article.js`
- карточки на главной ведут на реальные страницы
- поиск ищет по базе материалов
- сохранена совместимость с GitHub Pages
