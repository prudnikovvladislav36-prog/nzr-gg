# NZR.GG v1.0

- Убран TOURNAMENTS из основной навигации и плашка SOON.
- HERO теперь динамический: показывает опубликованный Featured-материал (или самый свежий, если Featured не задан).
- Убрана непонятная метка `01 / 04 · EDITOR'S PICK`; вместо неё выводится дата материала.
- Главная и блок «Последнее» работают от единой базы `content.js`.
- Admin превращён в CMS: после проверки GitHub отображает список материалов.
- Добавлено редактирование существующих материалов.
- Добавлено удаление материалов с подтверждением.
- Можно снимать материал с публикации через `Опубликовать сразу` и возвращать обратно.
- Featured управляется из CMS; при выборе нового Featured предыдущий автоматически снимается.
- При редактировании можно заменить обложку или сохранить текущую.
- Обновлён cache-busting ресурсов до v1.0.
