# Публикация материалов в NZR.GG v0.7

Теперь для обычной новости **не нужно создавать HTML-страницу**.

## 1. Подготовьте обложку
Положите изображение в папку `assets/`, например:

`assets/fable-release-date.jpg`

Используйте короткое имя латиницей, без пробелов.

## 2. Откройте `content.js`
Найдите массив:

`articles: [ ... ]`

Скопируйте один существующий объект и вставьте его в начало массива.

## 3. Заполните поля

```js
{
  slug: "fable-release-date",
  category: "news",
  published: true,
  featured: true,
  date: "2026-09-01",
  dateLabel: "1 сентября 2026",
  author: "NZR.GG Editorial",
  title: "Заголовок материала",
  excerpt: "Короткое описание для карточки и вступления.",
  image: "assets/fable-release-date.jpg",
  comments: 0,
  tags: ["fable", "xbox", "rpg"],
  body: [
    "Первый абзац.",
    "Второй абзац — на странице статьи он визуально выделяется.",
    "Третий абзац."
  ]
}
```

## 4. Что делает сайт автоматически

После commit материал автоматически:
- появляется в своей рубрике;
- становится доступен по `article/?slug=...`;
- попадает в поиск;
- участвует в блоке похожих материалов;
- получает теги, дату и автора;
- не показывается, если `published: false`.

## Категории

- `news`
- `esports`
- `updates`
- `industry`

## Черновики

Для подготовки материала без публикации:

`published: false`

После завершения просто поменяйте на:

`published: true`

## Важно

`slug` должен быть уникальным для каждой публикации.

Для рутинного ведения сайта обычно меняются только:
1. `content.js`
2. новая картинка в `assets/`

Commit для публикации можно называть, например:

`Publish: Fable release date`
